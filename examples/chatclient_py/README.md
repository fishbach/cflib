# Python chat client (chatclient_py)

A Python implementation of a client for the cflib `chatserver` example, built on
the Python runtime in [`py/`](../../py) and the generated service/DAO stubs in
`../chatserver/remote/chatserver/py/`.

It mirrors the JavaScript browser client: it connects over a WebSocket, speaks the
same hand-written BER protocol, subscribes to the `newMessage` remote signal, and
sends typed lines as chat messages.

## Run

1. Build cflib and start the server:

   ```bash
   cmake --build build
   ./bin/chatserver         # listens on port 8000
   ```

2. In another terminal, run the client (uv installs `cflib` + `websockets`):

   ```bash
   cd examples/chatclient_py
   uv run python main.py
   ```

Type a message and press enter; every connected client (Python, browser, ...)
receives it via the `newMessage` signal. Press Ctrl-D to quit.

## Regenerating the stubs

The `chatserver/remote/.../py/` stubs are generated by the export step
(`cf_remote`), the same way the `.js` browser stubs are:

```bash
./bin/chatserver --export examples/chatserver/remote
```
